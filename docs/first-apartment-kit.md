# First Apartment, Less Waste

Released as an ungated free ETLH resource in September 2026 at the owner's request.
No payment, email signup, account, or additional subscription is needed.

## Published files

- `/tools/first-apartment-kit.html`: self-contained, responsive browser planner.
- `/downloads/first-apartment-less-waste-v1.pdf`: four-page printable companion.
- `src/components/FirstApartmentKitCard.tsx`: discovery card on the existing Resources page.

The standalone HTML deliberately requires no framework, network API, external font,
third-party script, backend, or new package dependency. Keep it usable as an offline
file. Existing site navigation and resources remain unchanged.

## Scope and calculations

24 optional item prompts, custom items (60 total maximum), 18 adaptable checklist
steps, and up to eight measurement checks. All prices are entered by the reader.
Currency is explicitly USD. Calculations use integer cents. Blank buy-now prices
are called out as incomplete, not represented as free items. Later items, already
owned items, borrowing, and skipped items are excluded from the buy-now estimate.
The remaining estimate is budget minus buy-now prices, other costs, and the buffer.
This is a planning estimate, not an actual spending ledger.

Measurements compare width, depth, and height in the entered orientation. Unit
selection only labels the numbers; it does not convert them. The tool cannot assess
rotations, delivery routes, assembly, required clearances, or actual safety. Suggested
checklist dates are not legal, lease, property, or provider deadlines.

## Privacy and portability

- No analytics, ads, form submission, or data API inside the standalone planner.
- The Resources card uses existing consent-aware analytics only for generic resource
  open/download events. No entered field values are transmitted.
- State stays in memory by default. Optional localStorage uses
  `etlh-first-apartment-v1`. Opting out removes that browser copy.
- Browser saving is not cross-device sync and is inappropriate on shared profiles.
- JSON backup/import uses schema version 1, validates size and fields, renders text
  safely, and asks before replacing a plan. Invalid imports leave the plan intact.
- CSV is an item-list export, not a restorable backup; formula-like text is escaped.
- Print creates a filled-in plan. Downloading the HTML saves the tool, not its state;
  export the JSON backup separately to carry a plan to another device or offline file.

## Maintenance

The PDF is generated by `scripts/generate-first-apartment-kit.py` using ReportLab.
Run `python scripts/generate-first-apartment-kit.py` in an authoring environment with
ReportLab installed, then visually inspect all four pages. ReportLab is not needed
for website builds. Keep PDF/HTML wording and their version identifiers aligned.
Avoid introducing medical, financial, legal, safety, savings, or environmental claims
without appropriate evidence and review. No invented prices or savings claims.

## Verification

`tests/accessibility/first-apartment-kit.spec.ts` runs in the existing desktop and
mobile Chromium CI projects: axe WCAG A/AA, layout overflow, downloadable PDF,
budget arithmetic, blank versus zero, input validation, native browser persistence,
JSON round-trip, rejected imports, dimensions, and calendar offsets.

Local pre-publication tests additionally covered CSV injection escaping, reset,
custom item handling, printing, zero editing network requests, and 320/390/768/1024
pixel layouts. The local renderer used an in-memory document and a storage stub;
native persistence is covered by the repository browser tests rather than inferred
from that local test.

## Rollback

Revert the release commit normally. Do not force-push or rewrite published history.
Removing the card alone hides discovery but leaves direct URLs available. Preserve
old versioned downloads when linking from already-shared materials.
